# 🎬 메가박스 3관 실시간 좌석 추첨 시스템 구축 가이드

본 문서는 **5학년 1·2반, 6학년 1·2반(총 56명)** 학생과 선생님들이 각 교실에서 서로 다른 기기(스마트폰, 태블릿, PC)로 접속하여 실시간으로 자리를 뽑고, 중복 배정 없이 결과를 공유할 수 있는 웹 애플리케이션의 전체 코드 및 배포 절차를 담고 있습니다.

---

## 📌 1. 프로젝트 주요 사양

- **좌석 구성 (총 65석 중 56명 배정)**:
  - **B열**: B3 ~ B15 (13석)
  - **C열**: C3 ~ C15 (13석)
  - **D열**: D3 ~ D15 (13석, 16번 제외)
  - **E열**: E3 ~ E15 (13석, 가운데 X석 포함, 16번 제외)
  - **F열**: F3 ~ F15 (13석, 가운데 X석 포함, 16번 제외)
- **학급 정원 (총 56명)**:
  - 5학년 1반: 15명
  - 5학년 2반: 14명
  - 6학년 1반: 13명
  - 6학년 2반: 14명
- **실시간 기술**: Google Firebase Realtime Database (WebSocket 기반 자동 반영)
- **호스팅**: Vercel (정적 웹 호스팅)

## 🔑 2. Firebase 무료 DB 세팅 (1회만 진행, 약 3분 소요)

각 교실의 화면이 서로 실시간으로 연결되려면 무료 클라우드 데이터베이스가 필요합니다.

1. [Firebase 콘솔](https://console.firebase.google.com/) 접속 후 구글 로그인.
2. **프로젝트 추가** 클릭 후 프로젝트 이름 입력 (예: `megabox-seat`) -> Google 애널리틱스는 해제 후 프로젝트 생성.
3. 좌측 메뉴 **빌드(Build) > Realtime Database** 선택 후 **데이터베이스 만들기** 클릭.
4. 위치는 기본(미국) 선택 후 다음 -> 보안 규칙 설정에서 **"테스트 모드로 시작"** 선택 후 사용 설정.
   - *테스트 모드는 30일간 인증 없이 읽기/쓰기가 가능하여 수업용/행사용으로 가장 편리합니다.*
5. 좌측 상단 톱니바퀴 아이콘(**프로젝트 설정**) 클릭.
6. 하단 '내 앱' 섹션에서 **웹 아이콘 `</>`** 클릭 -> 앱 닉네임 입력 후 앱 등록.
7. 화면에 나타나는 `firebaseConfig` 객체 값을 복사해 둡니다.

```javascript
// 예시: 아래와 같은 형식의 설정값이 발급됩니다.
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "megabox-seat.firebaseapp.com",
  databaseURL: "https://megabox-seat-default-rtdb.firebaseio.com",
  projectId: "megabox-seat",
  storageBucket: "megabox-seat.appspot.com",
  messagingSenderId: "...",
  appId: "..."
};
```

    // B~F열 전체 (3~15번, 총 65석 풀)
    const SEAT_ROWS = ['B', 'C', 'D', 'E', 'F'];
    const ALL_SEATS = [];
    SEAT_ROWS.forEach(r => {
      for (let i = 3; i <= 15; i++) {
        ALL_SEATS.push(`${r}${i}`);

    let isDrawing = false;

    // 학년/반에 따른 번호 옵션 렌더링

      const g = document.getElementById('gradeSel').value;
      const c = document.getElementById('classSel').value;
      const max = CAPACITIES[`${g}-${c}`] || 15;
      const sel = document.getElementById('numSel');
      sel.innerHTML = '';
      for (let i = 1; i <= max; i++) {
        const opt = document.createElement('option');
        opt.value = i;
        opt.innerText = `${i}번`;

    // 학생 중복 배정 여부 검사
    function checkStatus() {
      const g = document.getElementById('gradeSel').value;
      const c = document.getElementById('classSel').value;
      const n = document.getElementById('numSel').value;
      const key = `${g}-${c}-${n}`;

      let assignedSeat = null;
      for (const [seat, info] of Object.entries(currentAssignments)) {
        if (info && info.key === key) {
          assignedSeat = seat;
          break;
        }
      }

      const notice = document.getElementById('statusNotice');
      const btn = document.getElementById('drawBtn');

      if (assignedSeat) {
        notice.innerText = `⚠️ 이미 배정 완료된 학생입니다. (좌석: ${assignedSeat})`;
        notice.className = 'w-full py-2 px-3 rounded-lg bg-rose-950/60 border border-rose-500/50 text-center text-xs font-bold mb-4 text-rose-300';
        btn.disabled = true;
        btn.classList.add('opacity-40', 'cursor-not-allowed');
      } else {
        notice.innerText = `✨ ${g}학년 ${c}반 ${n}번 학생은 추첨 가능합니다.`;
        notice.className = 'w-full py-2 px-3 rounded-lg bg-slate-950 border border-slate-800 text-center text-xs font-semibold mb-4 text-emerald-400';
        btn.disabled = false;
        btn.classList.remove('opacity-40', 'cursor-not-allowed');
      }
    }

    // 좌석판 렌더링
    function renderBoard(highlightSeat = null) {
      const grid = document.getElementById('boardGrid');
      grid.innerHTML = '';

      SEAT_ROWS.forEach(row => {
        const rowDiv = document.createElement('div');
        rowDiv.className = 'flex items-center gap-1.5 justify-center';

        const label = document.createElement('div');
        label.className = 'w-6 text-center font-black text-slate-500 text-sm';
        label.innerText = row;
        rowDiv.appendChild(label);

        for (let num = 3; num <= 15; num++) {
          const seatId = `${row}${num}`;
          const info = currentAssignments[seatId];
          const seatBox = document.createElement('div');
          seatBox.id = `seat-${seatId}`;
          seatBox.className = 'w-11 h-11 rounded-lg border flex flex-col items-center justify-center p-0.5 text-center transition';

          if (info) {
            let colorCls = 'bg-slate-800 border-slate-700 text-slate-200';
            if (info.key.startsWith('5-1')) colorCls = 'bg-sky-200 border-sky-400 text-sky-950 font-bold';
            else if (info.key.startsWith('5-2')) colorCls = 'bg-emerald-200 border-emerald-400 text-emerald-950 font-bold';
            else if (info.key.startsWith('6-1')) colorCls = 'bg-amber-200 border-amber-400 text-amber-950 font-bold';
            else if (info.key.startsWith('6-2')) colorCls = 'bg-pink-200 border-pink-400 text-pink-950 font-bold';

            seatBox.className += ` ${colorCls}`;
            seatBox.innerHTML = `

            seatBox.classList.add('winner-seat');
          }

          rowDiv.appendChild(seatBox);
        }

        grid.appendChild(rowDiv);
      });
    }

    // 추첨 실행 (Firebase DB 트랜잭션/원자적 기록)
    async function executeDraw() {
      if (isDrawing) return;

      const g = document.getElementById('gradeSel').value;
      const c = document.getElementById('classSel').value;
      const n = document.getElementById('numSel').value;
      const key = `${g}-${c}-${n}`;

      // 빈 좌석 리스트 추출
      const vacantSeats = ALL_SEATS.filter(s => !currentAssignments[s]);
      if (vacantSeats.length === 0) {
        alert('모든 좌석이 배정 완료되었습니다.');
        return;
      }

      isDrawing = true;
      const pickedSeat = vacantSeats[Math.floor(Math.random() * vacantSeats.length)];
      const studentData = {
        key: key,
        grade: parseInt(g),
        classNum: parseInt(c),
        studentNum: parseInt(n),
        assignedAt: new Date().toISOString()
      };

      try {
        // Firebase에 저장 (실시간 동기화 트리거)
        await window.dbSet(window.dbRef(window.db, `assignments/${pickedSeat}`), studentData);

        // 모달 띄우기
        document.getElementById('modalStudentName').innerText = `${g}학년 ${c}반 ${n}번 학생`;
        document.getElementById('modalSeatId').innerText = pickedSeat;
        document.getElementById('ticketModal').classList.remove('hidden');
        document.getElementById('ticketModal').classList.add('flex');

        renderBoard(pickedSeat);
      } catch (err) {
        alert('좌석 저장 중 오류가 발생했습니다: ' + err.message);
      } finally {
        isDrawing = false;
        checkStatus();
      }
    }

    function closeModal() {
      document.getElementById('ticketModal').classList.add('hidden');
      document.getElementById('ticketModal').classList.remove('flex');
    }

    function toggleAdmin() {
      document.getElementById('adminPanel').classList.toggle('hidden');
    }

    // 엑셀(CSV) 다운로드
    function downloadCSV() {
      let csv = "\uFEFF좌석번호,학년,반,번호,배정일시\n";
      ALL_SEATS.forEach(seat => {
        const info = currentAssignments[seat];
        if (info) {
          csv += `"${seat}","${info.grade}","${info.classNum}","${info.studentNum}","${info.assignedAt}"\n`;
        }
      });
      const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' });
      const a = document.createElement('a');
      a.href = URL.createObjectURL(blob);
      a.download = `메가박스3관_좌석배정_${new Date().toISOString().slice(0, 10)}.csv`;
      a.click();
    }

    // 전체 초기화
    async function resetAllSeats() {
      if (confirm('정말로 모든 학생의 좌석 배정 데이터를 삭제할까요?')) {
        await window.dbSet(window.dbRef(window.db, 'assignments'), null);
        alert('모든 좌석이 초기화되었습니다.');
      }
    }

    // Firebase 실시간 리스너 연결
    window.addEventListener('load', () => {
      onClassChange();
      renderBoard();

      // Firebase 초기화 완료 대기
      const checkInterval = setInterval(() => {
        if (window.db) {
          clearInterval(checkInterval);
          const assignmentsRef = window.dbRef(window.db, 'assignments');
          
          // 실시간 데이터 변경 감지 (누군가 자리를 뽑으면 즉시 자동 실행)
          window.onValue(assignmentsRef, (snapshot) => {
            currentAssignments = snapshot.val() || {};
            renderBoard();
            checkStatus();
          });
        }
      }, 100);
    });
  </script>
</body>
</html>

## 🚀 4. GitHub & Vercel 배포 방법

### 1단계: GitHub에 코드 올리기
1. [GitHub](https://github.com)에 로그인 후 **New Repository**를 클릭합니다.
2. Repository name에 `megabox-seat-picker` 입력 후 **Public** 체크, **Create repository**를 누릅니다.
3. 생성된 저장소 화면에서 **`uploading an existing file`** 링크를 클릭합니다.
4. 방금 만든 `index.html` 파일을 드래그하여 올린 뒤 맨 밑 **Commit changes**를 클릭합니다.

### 2단계: Vercel로 1분 배포
1. [Vercel](https://vercel.com)에 접속하여 **GitHub 계정으로 로그인**합니다.
2. 대시보드에서 **`Add New...` > `Project`** 클릭.
3. 방금 만든 `megabox-seat-picker` 저장소 옆의 **`Import`** 버튼을 누릅니다.
4. 추가 설정 없이 화면 하단의 **`Deploy`**를 클릭합니다.
